# EtherShield

نظام دفاع سيبراني مناعي واستباقي يحلل الروابط الاحتيالية بالذكاء الاصطناعي. طوّرناه من فحص تقليدي للروابط إلى منظومة تتنبأ بالفخ عبر ثلاثة محركات:

- **التوأم الرقمي الوهمي:** يفتح الرابط نيابةً عن المستخدم.
- **محرك نية الاستدراج النفسي:** يحلل أساليب الضغط في الرسالة.
- **شبكة المناعة التشاركية:** تولّد مصلًا رقميًا لحظيًا يحظر التهديد عن جميع المستخدمين.

> الموقع نموذج أولي تفاعلي. مختبر الفحص فيه محاكاة توضيحية تعمل داخل المتصفح، وليس فحصًا حقيقيًا للروابط.

## هيكل المشروع

```
EtherShield/
├── index.html        الصفحة الرئيسية
├── css/style.css     التنسيقات (يدعم الوضع الفاتح والداكن)
├── js/main.js        التفاعلات والرسوم المتحركة
└── assets/           الشعار وأيقونة الدرع
```

## التشغيل محليًا

افتح ملف `index.html` في المتصفح مباشرة، لا يحتاج أي تثبيت.

## النشر على GitHub Pages

1. ارفع محتويات المجلد إلى مستودع جديد على GitHub.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
3. بعد دقيقة تقريبًا يظهر رابط الموقع في نفس الصفحة.
